Batch Size

批大小

定义

每次参数更新所用训练样本的数量。batch 大，梯度估计稳、硬件利用率高、但更新次数少、泛化可能变差；batch 小则相反。它是训练超参数中对显存占用和收敛速度影响最直接的一个，常以 2 的幂取值。

示例

  • 显存不够时减小 batch 或改用梯度累积等效放大。
  • 小 batch 训练loss 抖动大但常能找到更平的极小值。
  • 学习率通常要随 batch 大小按比例调整。
