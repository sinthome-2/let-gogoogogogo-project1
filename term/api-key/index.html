API Key

API 密钥

定义

用于标识和认证 API 调用者身份的字符串。调用 OpenAI、Claude 等模型服务通常需要提供 API key。

示例

  • 不要把 API key 硬编码在公开代码仓库中。
  • API key 泄露可能导致账户被盗用。
  • 生产环境常通过环境变量管理 API key。
