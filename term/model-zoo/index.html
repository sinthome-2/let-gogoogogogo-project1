Model Zoo

模型动物园

定义

集中存放和分享预训练模型及其配置文件的平台或仓库。研究者可以从中下载模型用于微调或推理。

示例

  • Hugging Face Hub 是目前最大的 model zoo 之一。
  • TensorFlow Hub、PyTorch Hub 也提供大量预训练模型。
  • Model zoo 加速了研究和应用开发。
