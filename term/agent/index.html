Agent

智能体

定义

能够感知环境、自主决策并调用工具完成目标的 AI 系统。Agent 不仅能生成文本，还能执行代码、查询数据库、浏览网页等。

示例

  • 能自动订机票、查天气并写行程的 AI 助手。
  • 代码 Agent 可以读取文件、运行测试并修复 bug。
  • Agent 通常由 LLM 作为'大脑'，配合工具链使用。
